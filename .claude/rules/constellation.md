# Constellation

This repo is a member of the constellation vault `magnetic-rose`, which is the parent
directory `../..`. The vault holds the glossary (`../../CONTEXT.md`), decision
records (`../../decisions/`), epic maps (`../../epics/`) and the Beads tracker
(`../../.beads`, reached from here via `.beads/redirect`).

Sibling member repos of the same vault:
- `../constellation`
- `../cc-plugins`
Recursive search from this directory does not enter the vault or the siblings. To search
them, name the directory as an explicit path.

Workflow configuration for skills is in `docs/agents/`. These files and `.beads/redirect`
are generated by `constellation rebuild`; edit the vault manifest, not these files. The
redirect is machine-local - `rebuild` keeps it out of git via `.git/info/exclude`.
