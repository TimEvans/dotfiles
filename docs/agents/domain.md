# Domain docs

This repo is a member of the constellation vault `magnetic-rose`. The unit shares one
glossary and one set of decision records, both in the vault, not in this repo.

## Before exploring, read these

- **`../../CONTEXT.md`** - the unit's ubiquitous language. Challenge terms against it;
  update it inline when a term is resolved.
- **`../../decisions/`** - architecture decision records for every member and for
  cross-repo decisions. Read the ones that touch the area you are about to work in.

## Where to write

- New glossary terms: `../../CONTEXT.md`.
- New decisions: `../../decisions/NNNN-<slug>.md`, numbered from the highest existing.
  Do not create `CONTEXT.md` in this repo.

Single-context layout. There is no `CONTEXT-MAP.md`.
